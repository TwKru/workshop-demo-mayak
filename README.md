# Маяк — демонстрационный сайт для мастерской

Независимый демонстрационный концепт, не официальный сайт мастерской и не подтверждённый клиентский заказ.

Статический HTML/CSS/JS без сборки и серверной части. Подходит для GitHub Pages из ветки main, корень /.

Форма создаёт текст заявки и открывает WhatsApp. Пользователь сам нажимает «Отправить» в чате. Получатель в этой демонстрации — тестовый контакт разработчика, указанный в config.js. Заявки не бронируют время автоматически. Данные формы не сохраняются на сайте, серверных запросов и аналитики нет.

Прайс и адрес взяты из публичной карточки для примера: https://yandex.ru/maps/org/shinomontazh/123816901053/prices/. Перед рабочим запуском все сведения согласовываются с владельцем. Количество колёс в единице прайса источником не подтверждено, итоговую стоимость подтверждает мастер.

Публичный пакет не содержит .env, токенов бота, базы контактов и серверного кода. Для изменения получателя используется config.js. Настоящие пароли туда добавлять нельзя.

Шрифт Golos Text включён локально. Лицензия SIL OFL 1.1: assets/OFL.txt. Запросов к Google Fonts нет.
